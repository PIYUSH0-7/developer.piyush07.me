## 📦 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PIYUSH0-7/developer.piyush07.me.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build production bundle:**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages manually:**
   ```bash
   npm run deploy
   ```
